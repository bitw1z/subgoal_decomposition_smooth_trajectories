Subgoal Decomposition for Smooth Robotic Manipulation

Investigating robust subgoal extraction for hierarchical manipulation policies when demonstrations do not contain explicit pauses.

Overview Motivation Method Contributions Results

Project Overview

Long-horizon robotic manipulation tasks are challenging because they require a robot to execute many sequential actions in the correct order over extended periods of time. Learning these behaviors using a single monolithic policy is difficult, since the policy must simultaneously reason about high-level task progression and low-level motion control across long temporal horizons.

As task complexity increases, this often leads to inefficient learning and poor generalization. This project studies how subgoal decomposition can make long-horizon robotic manipulation more stable, interpretable, and scalable.

Central Question: How can we extract meaningful subgoals from smooth manipulation trajectories where explicit pauses are removed?

Motivation

Subgoals provide an effective way to decompose a complex manipulation task into a sequence of intermediate objectives. This hierarchical decomposition reduces the effective planning horizon and allows high-level policies to focus on task progression, while low-level controllers execute short-horizon motions to reach each subgoal.

State-of-the-art manipulation methods on RLBench, such as PerAct and RVT, commonly rely on simple heuristic-based subgoal decomposition. In these approaches, keyframes are typically selected when joint velocities are near zero or when the gripper open/close state changes.

This heuristic works effectively on standard RLBench demonstrations because many trajectories contain explicit pauses before important actions such as grasping, pushing, or placing objects. These pauses naturally create detectable transition points for subgoal extraction.

However, this assumption becomes problematic when trajectories are smooth and no longer contain explicit pauses. Important task transitions may occur continuously without near-zero velocities, causing heuristic-based methods to miss meaningful subgoals or generate unreliable decompositions.

Method

To investigate this limitation, we first smooth RLBench demonstrations to remove explicit pauses while preserving the original task behavior. This creates a more challenging benchmark setting where pause-based keyframe extraction becomes unreliable.

We then develop a subgoal decomposition framework for smooth manipulation trajectories using hierarchical policies based on RVT-2 and goal-conditioned DP3. Instead of relying only on pause-based heuristics, our method extracts meaningful intermediate subgoals from continuous trajectories and uses them to train both the high-level and low-level policies.

1. Smooth Demonstrations

RLBench trajectories are smoothed to remove artificial pauses while preserving task-relevant motion structure.

2. Subgoal Extraction

Meaningful intermediate subgoals are extracted from continuous end-effector trajectories instead of relying only on near-zero velocity events.

3. Hierarchical Policy Learning

RVT-2 predicts high-level subgoals, while goal-conditioned DP3 learns short-horizon motion policies to reach those subgoals.

Major Contributions

  • We identify that existing RLBench-based subgoal extraction methods rely heavily on artificial pauses in demonstrations.
  • We introduce a smooth-trajectory benchmark setting where traditional velocity-based heuristics become unreliable.
  • We show that trajectory-based subgoal decomposition provides more stable keyframe selection under smooth demonstrations.
  • We evaluate the effect of subgoal decomposition on hierarchical policy learning using RVT-2 and goal-conditioned DP3.

Experimental Findings

Experimental results show that the proposed subgoal decomposition method improves hierarchical manipulation performance on smooth trajectories compared to conventional heuristic-based approaches.

These results suggest that robust subgoal extraction is critical for hierarchical robotic manipulation, particularly in realistic settings where demonstrations do not contain artificially separated motion segments.

Key Takeaway: Hierarchical manipulation policies depend strongly on the quality of extracted subgoals. When demonstrations become smooth, pause-based heuristics are no longer sufficient.
